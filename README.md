# simple-web-clock

A fullscreen browser clock. Works offline using the machine's system time.

## Local/Offline usage:

Clone and open `index.html` in a browser. 

No build step, no dependencies.

## Hosting:

Deployed to GitHub Pages as-is. See: [simple-web-clock](lepari23.github.io/simple-web-clock/) 

## Features:

- Light / dark mode
- Clock styles: digital and analog
- Per-component colours (hours, minutes, seconds)
- Optional seconds display
- Optional date display with format options
- 12hr / 24hr toggle
- Fullscreen button
